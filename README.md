# AG-Tasks Desktop – Downloads

Installer und automatische Updates für **AG-Tasks Desktop**: deine Karten aus AG Tasks als Kurznotizen auf dem Windows-Desktop.

## Installieren

1. Unter [Releases](https://github.com/hanklandry/AG-Tasks-Desktop-Releases/releases/latest) die Datei `AG-Tasks-Desktop-Setup-<Version>.exe` herunterladen.
2. Ausführen. Der Installer ist nicht signiert – bei der SmartScreen-Warnung **„Weitere Informationen“ → „Trotzdem ausführen“**.
3. Beim ersten Start über agrp.me / Discord anmelden.

Voraussetzungen: Windows 10/11 (64-Bit) und ein Zugang zu AG Tasks.

## Updates

Ab Version 0.3.0 aktualisiert sich die App selbst: Sie lädt neue Versionen im Hintergrund und installiert sie beim Beenden oder über „Jetzt neu starten“. Abschaltbar in den Einstellungen der App.

---

In diesem Repository liegen nur die fertigen Installer; der Quellcode wird separat gepflegt. Die Dateien `latest.yml` und `*.blockmap` an den Releases braucht die App für ihre Updates.
